# NintendoPosterMaker

![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)

**Nintendo Switch のおすすめゲームを布教したい人向けのツールです。**  
紹介したいゲームを最大10本選ぶだけで、X（Twitter）にそのまま投稿できる高画質まとめポスターを自動生成します。

---

## 出力サイズ

| モード | サイズ | 用途 |
|--------|--------|------|
| 横型（Horizontal） | 1920 × 1080 px | PC向け・横長ツイート |
| 縦型（Vertical） | 1080 × 1920 px | スマホ向け・縦長ストーリー |
| 正方形（Square） | 1080 × 1080 px | インスタ・正方形ツイート |

---

## 使い方

| STEP | 操作 |
|------|------|
| 1 | 「ゲームを追加」検索バーにタイトルを入力して検索 |
| 2 | 候補から選んで「追加」ボタンを押す |
| 3 | 各スロットの「編集」ボタンからレビュー文を入力して「保存」 |
| 4 | デザイン設定（テーマ・カバーアート・出力サイズ）を調整 |
| 5 | 「ポスターを生成する」→ PNG をダウンロード → X に投稿 |

> ゲームは最大10本。空のスロットは「空欄カード」としてポスターに自動配置されます。

---

## 主な機能

### ゲーム入力

| 機能 | 説明 |
|------|------|
| クイック追加バー | ページ上部の検索バーからゲームを検索して次の空きスロットに即追加 |
| キーワード検索 | 日本語・英語タイトルで IGDB 検索。上位10件＋カバー画像プレビュー付き |
| スロット編集 | 各スロットの「編集」ボタンからレビュー文の入力・ゲームの差し替えが可能 |
| ドラッグ＆ドロップ並べ替え | 「並び替え」モードでスロットの順序を変更 |
| 全スロット一括クリア | 確認ダイアログ付きのリセット機能 |

### ポスターデザイン

| 機能 | 説明 |
|------|------|
| 出力サイズ | 横型 / 縦型 / 正方形 の3択 |
| ゲーム数 | 8本 / 10本 を選択（カードサイズ自動調整） |
| 全体見出し | ON/OFF 切り替え可能。最大25文字 |
| テーマカラー | 5種類（下表参照） |
| 背景スタイル | ぼかし（強度スライダー）/ 単色 の2択 |
| カバーアートモード | ボックスアート（縦型・contain）/ スクリーンショット（横型・cover）の2択 |
| Metacritic バッジ | スコアに応じて緑 / 黄 / 赤で表示。非表示切り替えも可能 |

### その他

| 機能 | 説明 |
|------|------|
| 言語切り替え | 画面右上のトグルで 日本語 / English を切り替え |
| X シェア | ダウンロード後にワンクリックでシェア投稿画面を開く |
| ウォーターマーク | フッターに `Generated by NintendoPosterMaker` を自動挿入 |

## IGDB API 認証情報の設定

本アプリは [IGDB API](https://api-docs.igdb.com/) を使用するため、**Twitch Developer アカウント**が必要です。

### 1. Twitch Developer Portal で認証情報を取得

1. [Twitch Developer Console](https://dev.twitch.tv/console) にアクセス
2. 「Register Your Application」でアプリを登録
3. **Client ID** と **Client Secret** を控える

### 2. Streamlit Secrets に設定

#### ローカル開発時

`.streamlit/secrets.toml` を作成（`.gitignore` 対象、コミット禁止）:

```toml
IGDB_CLIENT_ID     = "あなたのClient ID"
IGDB_CLIENT_SECRET = "あなたのClient Secret"
```

#### Streamlit Community Cloud デプロイ時

1. [share.streamlit.io](https://share.streamlit.io) でアプリを開く
2. アプリの設定 → 「Secrets」に以下を追加:

```toml
IGDB_CLIENT_ID     = "あなたのClient ID"
IGDB_CLIENT_SECRET = "あなたのClient Secret"
```

## ローカルでの開発・実行

### 必要環境

- Python 3.10 以上
- IGDB API の認証情報（上記参照）

### セットアップ

```bash
git clone https://github.com/HERO-Yuki/App_041_NintendoPosterMaker.git
cd App_041_NintendoPosterMaker
pip install -r requirements.txt
# .streamlit/secrets.toml を作成して認証情報を設定
streamlit run app.py
```

### 初回起動時の注意

日本語フォント（Noto Sans CJK JP Bold）を自動ダウンロードします（初回のみ、約30秒）。

### ディレクトリ構成

```
App_041_NintendoPosterMaker/
├── app.py                   # メイン（Streamlit アプリ全体）
├── requirements.txt
├── README.md
├── .gitignore
└── .streamlit/
    ├── config.toml          # Nintendo レッドの UI カラーテーマ
    └── secrets.toml         # IGDB 認証情報（.gitignore 対象）
```
